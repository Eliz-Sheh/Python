📊 Ecommerce Sales Analytics
Анализ датасета продаж интернет-магазина с 5000 заказов. Проект включает полный исследовательский анализ данных (EDA), визуализацию ключевых метрик и бизнес-рекомендации.

🎯 Цель проекта
Провести исследовательский анализ данных о продажах интернет-магазина

Выявить ключевые тренды и паттерны в поведении покупателей

Проанализировать распределение выручки и определить клиентские сегменты

Разработать практические бизнес-рекомендации для каждой категории товаров

📊 Данные
Источник: Ecommerce Sales Dataset (5000 записей)

Структура данных:

order_id — идентификатор заказа

order_date — дата заказа (2022–2034 гг.)

customer_id — идентификатор клиента

product_category — категория товара (Electronics, Clothing, Home, Beauty)

region — регион (West, North, East, South)

quantity — количество товаров в заказе

unit_price — цена за единицу товара

discount — скидка

payment_method — способ оплаты (Card, COD, Wallet)

delivery_days — срок доставки (дней)

customer_rating — оценка клиента (1–5)

revenue — выручка

🛠 Используемые технологии
Pandas — обработка и очистка данных

NumPy — числовые вычисления

Matplotlib / Seaborn — визуализация данных

Jupyter Notebook — интерактивная среда разработки

🔍 Этапы анализа
1. Загрузка и первичный обзор данных
Проверка структуры данных, типов столбцов

Выявление пропусков и дубликатов — данные полностью чистые

2. Предварительный анализ
Распределение категорий:

Electronics — 1777 заказов (35.5%)

Clothing — 1531 заказов (30.6%)

Home — 969 заказов (19.4%)

Beauty — 723 заказа (14.5%)

Регионы: равномерное распределение (1208–1289 заказов)

Способы оплаты:

Card — 2270 (45.4%) — явный лидер

COD — 1774 (35.5%)

Wallet — 956 (19.1%)

3. Исследовательский анализ (EDA)
📈 Распределение выручки
Strong positive skew (правосторонняя асимметрия)

Mean (1022) > Median (797) > Mode (32)

Классический признак скошенного распределения с "длинным хвостом" вправо

💰 Выручка по категориям
Beauty — самая стабильная категория с высоким уровнем выручки

Electronics — высокие пики выручки, большие разбросы

Clothing — высокая вариативность, требует дополнительного анализа

Home — самая слабая категория по выручке

⭐ Оценки клиентов
Распределение близко к нормальному

Пик на оценках 4–5 — высокий уровень удовлетворённости

💳 Анализ способов оплаты
Доминирование карт (45%)

Минимальное использование кошельков (19%)

4. Ключевые инсайты
Три клиентских сегмента:

Массовый (mode = 32) — небольшие заказы, основа по объёму

Средний (до 797) — типичный чек

Премиум (>1000–4000) — редкие, но критичные для выручки
