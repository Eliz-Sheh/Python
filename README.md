## 🔑 Ключевые инсайты

### Три клиентских сегмента:

1. **Массовый** (`mode = 32`) — небольшие заказы, основа по объёму
2. **Средний** (до `797`) — типичный чек
3. **Премиум** (>`1000–4000`) — ***редкие, но критичные для выручки***

## 💡 Бизнес-рекомендации

### По категориям:

| Категория | Статус | Рекомендации |
|-----------|--------|--------------|
| **Beauty** | ✅ | Поддерживать текущую стратегию. Категория ***стабильна и эффективна*** |
| **Clothing** | ⚠️ | Разделить на подкатегории (мужская/женская, премиум/эконом). Проверить влияние ***сезонности*** и скидок |
| **Electronics** | 🚀 | Изучить причины крупных пиков (дорогие товары, оптовые заказы). ***Масштабировать успешные кейсы*** |
| **Home** | 📉 | Усилить ***маркетинговую активность***. Внедрить промоакции и кросс-продажи |

### Общие рекомендации:

1. Для прогнозов использовать ***медиану***, а не среднее
2. Стимулировать **массовый сегмент** к повышению чека через кросс-продажи
3. Выявить характеристики **крупных заказов** и масштабировать их
4. Применить **логарифмическое преобразование** для моделирования
